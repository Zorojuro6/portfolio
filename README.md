# Portfolio

Mon portfolio personnel : une page web statique qui présente mes projets de programmation.

## Contenu
- Présentation et liens vers six projets publiés sur GitHub.
- Une page unique en HTML et CSS, sans bibliothèque externe.

## Choix techniques
- HTML sémantique (`header`, `nav`, `main`, `section`, `article`, `footer`) et titres hiérarchisés.
- Mise en page avec Flexbox (navigation) et Grid (cartes de projets, nombre de colonnes automatique).
- Unités relatives (`rem`) pour respecter la taille de texte choisie par l'utilisateur.
- Contours de focus visibles et lien d'évitement pour la navigation au clavier.
- Couleurs définies par des variables CSS.

## Accessibilité
Ce que j'ai vérifié : navigation au clavier avec TAB, contraste, zoom 200 %.
